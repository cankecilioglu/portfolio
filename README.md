# cankecilioglu.dev

Personal site of **Can Keçilioğlu** — mechatronics engineer working across robotics,
AI and embedded systems. A home for my projects, experiments and writing.

**Live:** [cankecilioglu.dev](https://cankecilioglu.dev)

## Built with

- **[Astro](https://astro.build)** — static, zero-JS by default
- **[Tailwind CSS v4](https://tailwindcss.com)** with a custom design system
- **MDX** content collections for projects and writing
- Self-hosted typography (Helvetica · IBM Plex Mono)
- Deployed on **Cloudflare**

## Development

```bash
npm install     # install dependencies
npm run dev     # dev server → http://localhost:4321
npm run build   # production build → ./dist
```
